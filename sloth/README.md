# Sloth Language Extension

Sloth is a custom experimental programming language inspired by Python and C, designed for simplicity and educational purposes. This VS Code extension provides:

- Syntax highlighting for `.slw` files
- Language configuration (comments, brackets)
- Full support for your Sloth-based projects

## Features

✔️ Highlights Sloth keywords like `if`, `repeat`, `return`  
✔️ Supports strings and block comments `<< like this >>`  
✔️ Recognizes `.slw` files automatically

## Installation

### From Marketplace
Search for **Sloth_by_zonet** in the Extensions tab.

### Manual
1. Download `slothdemolang-0.0.1.vsix`
