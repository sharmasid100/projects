## Features
- Variables: let x = 10;

- Arithmetic: +, -, *, /, %, ()

- Comparison: ==, !=, <, >, <=, >=

- Conditionals: if, else

- Loops : repeat(condition) {body}

- Functions: do name(params) { body }

- Built-in: print(), input() , return 

- comments : <<This is a comment>>

- Array : let nums = [1, 2, 3, 4];
  print(nums[2]);  // should print 3
  nums[1] = 99;
  print(nums);  // should print [1, 99, 3, 4]

- let x: int = 5;
  let name: string = "Alice";
